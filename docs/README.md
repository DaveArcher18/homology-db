## Design and research archive

[Planning](planning/), [research](research/), [contracts](contracts/), and
[architecture decisions](adr/) retain the project's reasoning and earlier
directions. Their dates and scopes matter: older release counts, proposed
roadmaps, and review pauses are not descriptions of the current live atlas.

[TEST_DRIVE.md](TEST_DRIVE.md) and [EXTERNAL_REVIEW.md](EXTERNAL_REVIEW.md) include
historical fixture workflows; the latter's frozen review handoff is distinct
from the current family-review invitation.

The repository also retains internal work logs under `.scratch/`, `.underbite/`,
and `WORKSTATE.md`. These are implementation history, not a required contributor
process or a substitute for the current public guides.
