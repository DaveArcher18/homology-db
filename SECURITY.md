# Reporting security concerns

The atlas is a static site, but its HTML rendering, downloads, imported data,
and development scripts still deserve careful security review.

Please do not put credentials, private data, or sensitive exploit details in a
public issue. If GitHub offers **Report a vulnerability** under this repository's
Security tab, use that private route. Otherwise, open a minimal issue asking the
maintainer for a private reporting channel, without disclosing the vulnerability.
Do not assume private reporting is enabled.

Include the affected revision, a minimal reproduction, and likely impact once
a suitable channel is available. Test only systems and data you are authorized
to use. This side project does not promise a response deadline or a bounty.

Mathematical errors and ordinary display bugs belong in the normal issue forms.
