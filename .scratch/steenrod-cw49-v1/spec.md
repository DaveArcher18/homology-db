# Stable Steenrod modules and cw49 atlas specification

Implement the user-approved plan recorded in this effort's map. Success means
that the repository can load and validate all 49 cw49 spectra, deterministically
export every complete finite module to Bruner 1.9.5, sseq, and SSeqCpp, render
the records in a self-contained local atlas review artifact, and refuse public
release until the selected claims carry Dan Isaksen's acceptance.

The existing 42-space Snapshot, routes, and checked-in public artifact are
regression inputs and must remain available throughout development.
