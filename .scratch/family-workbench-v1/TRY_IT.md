# Try the family workbench

- Start on the home workbench with RP4. In the integral row compare H1 with H^1
  and H2 with H^2: torsion shifts degree. Change to RP5 and inspect the free top
  class and its products.
- Select complex projective spaces, n=100, first degree=194. Open the integral
  cup-product table and set its first additive-generator index to 97. The table
  shows u^97 through u^100 and clearly says it is a window, not incomplete math.
- Select S0: both groups have two degree-zero summands; the ring has e²=e.
  Toggle reduced homology: H0 loses one summand, the cohomology ring does not.
- Follow a coefficient knowl to the glossary; search for exterior algebra.
- Open Sources, review, and downloads. Read the RP integral derivation and
  use Review this family to inspect the prefilled GitHub form. Do not submit
  unless you are genuinely reviewing the identified rule. All initial rules
  remain human-review-pending.
